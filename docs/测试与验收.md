## 0.1.2 AI 凭据保存修复

用户在网页模拟器中读取模型、测试连接成功，但保存 AI 设置时报“安全凭据保存失败”。检查旧交付包发现：ARM64 主程序没有授权段，签名只包含代码目录，没有应用身份或钥匙串授权。旧工作流对模拟器使用 CODE_SIGNING_ALLOWED=NO；此前的设置测试只验证配置编解码，没有实际写入钥匙串。

本次修复为模拟器启用临时签名，并通过仅在 iphonesimulator SDK 使用的 Simulator.entitlements 配置应用身份与访问组。真机继续由个人签名及设备描述文件提供正式授权。钥匙串保存改为先更新、找不到再新增，写入失败不会先删除已有凭据；错误提示包含系统状态码，便于后续定位。

增加两项实际存储回归：钥匙串新增、覆盖、读取与删除；通过设置页同一保存入口写入虚构 AI 密钥，再创建新应用模型验证配置和密钥保留，并覆盖留空保留旧密钥、替换密钥的分支。工作流同时核验交付应用的签名与钥匙串访问组。测试不访问真实 AI 接口，不使用用户密钥。

## 群晖在线镜像部署

新增 deploy/synology 的专用 Compose、环境模板、Caddy 配置及中文操作说明。NAS 直接拉取 ghcr.io/nieten/jianfei-api:latest，使用持久化卷运行单实例 Python 后台。默认提供 18080 HTTP 入口，并保留 8443 HTTPS。部署包不包含数据库、账号凭据或 API 密钥；不需要导入本地镜像，也不需要在 NAS 构建。

镜像发布流程只在 main 执行，对 backend、deploy/synology、验收脚本及工作流本身的变更自动运行，同时支持手动触发。流程申请 contents: read 与 packages: write，使用 GitHub 临时工作流令牌发布到同一账号的 GHCR，不将个人令牌加入源码。候选镜像以提交 SHA 标记，通过两种架构的实际运行验收后才更新 latest；发布串行执行，不在合并请求中推送镜像。

部署验收覆盖实际发布镜像的后台回归、按内网 IP 建立 HTTP 与 HTTPS、从 Caddy 导出可读取的公开根证书、开户命令，以及重建容器后的文件和实例身份保留。首次验收发现并修复根证书导出后权限过严、IP 直连不发送 SNI 时无法选择证书的问题。IP 场景使用 default_sni 指定所配置地址，保留正常的证书链和地址校验。[Caddy 默认服务器名称说明](https://caddyserver.com/docs/caddyfile/options#default-sni)

## 0.1.3 HTTP 后台连接

首次设置和“私有服务器与账号”支持显式输入 HTTP，未指定协议仍默认 HTTPS。保存后自动复用协议、主机和端口，测试按钮和成功提示显示实际连接方式。仍拒绝带账号密码、查询参数、片段及非 HTTP/HTTPS 协议的后台地址。

iOS 属性表允许用户指定的 HTTP 后台，并移除会覆盖该规则的 NSAllowsLocalNetworking 键。HTTPS 继续使用系统证书信任，重定向仍由现有委托拒绝，避免隐式切换地址或协议。证书指纹配对仅接受 HTTPS，HTTP 用户通过设置页直接保存。[Apple ATS 例外规则](https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity/nsallowsarbitraryloads)

新增真实 TCP HTTP 服务测试，通过与设置页相同的保存与连接入口请求健康接口，重新创建应用模型后再连接，验证地址和协议保留；另覆盖 HTTP 地址规范化、默认 HTTPS 和 HTTP 不得声明证书指纹核验。测试服务在模拟器内部启动，不连接用户 NAS 或真实 AI 服务。

提交 13bd73638c80ee561aae51056ce9cfb2ab17a341 的 iPhone、Watch Release 编译和 19 项 XCTest 均通过，零失败，测试耗时 44.242 秒；实际 HTTP 连接及保存后重新加载测试耗时 0.290 秒。[0.1.3 构建与测试记录](https://github.com/NieTen/jianfei/actions/runs/42228178915)

## 二次优化记录

1. 首次启动引导保存后台地址和完成状态，后续启动复用，设置页保留修改入口。
2. AI 地址、模型、输出设置与密钥持久化，支持个人配置、模型列表和手动模型标识。
3. 趋势计算移出主线程，按日期和类型建立索引，切换条件时取消旧计算。
4. 图片使用 ImageIO 降采样，后台转换 JPEG，缩略图采用有容量上限的内存缓存。
5. 同步区分成功、失败和冲突，提供失败原因、重试和本机排队操作取消入口。
6. 账号及服务器切换时取消同步，过期会话响应停止应用，账号使用独立本地命名空间。
7. 删除后恢复餐次时生成新的记录和照片标识，手动合并先校验再提交。
8. 份量未知的 AI 候选需要用户确认。未知热量和营养素保留缺失状态。
9. 体重比较使用实际时间，避免不同时区的时间字符串排序错误。
10. 单位切换同步转换输入值，餐次模板在下一个统计日生效。
11. 识别任务中断后标为 unknown，内部任务恢复执行，删除意图独立持久化。
12. 备份复用哈希相同的加密附件，保留被有效备份引用的对象，支持单文件完整导出。
