# 首版开发清单

用户已确认本次包含原需求文档全部 P0、P1、P2。

## 当前实现范围

- 后台使用 Python、FastAPI、SQLite，采用单进程及持久化任务表。
- iOS 使用 SwiftUI、SQLite3、HealthKit、Vision、CryptoKit。
- 包含双人和最多八人的小组挑战、多设备、端侧分类、围度、睡眠与心率摘要、可选远程通知。
- Watch 提供体重及饮食快捷记录，通过持久化传输队列交给手机。

## 环境记录

- 当前工作目录为 Windows，已建立 Python 3.11 开发虚拟环境，生产镜像计划使用 Python 3.13。
- Docker 命令可用，开发开始时 Docker 服务未启动。
- 当前环境未发现 Swift、Xcode 或 macOS，iOS 与 Watch 真机编译签名需单独验证。
