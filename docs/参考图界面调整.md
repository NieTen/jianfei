# 参考图界面调整

本轮依据用户提供的三页参考图修改现有 SwiftUI 页面，保留已经完成的体重、记餐、初始化、同步和伙伴功能。用户明确要求确认改完后再统一打包，本轮不执行新的云端构建，也不生成安装包。

## 已调整的界面

- 首页采用青绿渐变摘要卡、渐变完成度圆环与底部柔和波纹；记餐和体重入口分别使用浅橙与浅紫背景。
- 主页面改为浅薄荷底色、白色圆角卡片、轻阴影、较紧凑的间距与左侧导航标题。
- 首页、饮食、趋势标题旁增加太阳山丘、食物与上升图表插画。装饰由 SwiftUI 图形和系统图标绘制，不增加图片下载或第三方依赖。
- 蛋白质、碳水和脂肪分别使用绿、橙、紫色，同时保留文字标签，不只依赖颜色区分。
- 趋势使用浅绿筛选条、绿色选中时间范围、渐变填充曲线、每日测量圆点与均线开关。默认仍同时展示体重和摄入，筛选中可以单独查看。
- 底部五个入口保留原 TabView 与各自 NavigationStack，选中项显示浅绿色圆角背景。
- 共用配色、卡片与按钮继续支持深色；标题和布局使用动态字体。装饰在辅助功能大字体下隐藏，让文字有足够空间。
- 日期仍位于体重录入第一项；首页日期继承、改日期清空重量、三餐按钮、相册自动识别、仅热量录入与身体信息引导均保留。

## 其他页面的统一

- 伙伴、我的、健康详情、三步初始化使用相同的页面间距与插画标题；新增伙伴、个人档案、健康和连接插画，仍由原生图形与系统图标绘制。
- 体重、记餐、食物详情、身体围度、个人档案、AI 接口、后台账号、健康权限、提醒、备份与恢复统一采用薄荷底色和分组卡片。体重与记餐保持紧凑，不增加顶部介绍卡。
- 邀请、创建或加入挑战、共享授权、账号恢复、同步冲突与字段合并弹层也同步调整。邀请页可滚动，适配较小屏幕。
- 表单保留原生 Form，列表保留原生 List；滑动操作、刷新、选择器、日期、输入绑定、网络操作与数据校验沿用原实现。统一表单增加收起键盘入口。
- 档案、围度、食物营养、后台地址、AI 地址与密钥、账号字段增加固定标签。账号红框、多项错误提示和删除操作的红色警示继续保留。
- 创建、加入、登录、保存 AI 配置、分享邀请等主要按钮统一使用青绿渐变，次要操作使用浅绿色背景。设置入口按绿色、橙色、紫色分色。
- 伙伴体重图统一使用绿色测量点、左侧刻度与浅色虚线网格，继续按查看者的本机单位展示，仅绘制实际授权的测量记录。

这轮只调整现有界面和共用样式，没有增加依赖，也未修改后台。现有截图验收流程新增档案、AI、后台账号、挑战创建、邀请和提醒页面的深浅色截图，以及部分大字体、小屏幕场景；这些截图将在下一次用户确认后的原生验收中采集。

## 预览与验证

本机 build/UI预览/参考样式.html 为独立的网页样式示意，包含三个页面及深浅色切换，使用示例数据，不连接后台、不保存记录。它不是 iOS 运行截图，不能代替原生布局验收。内置浏览器拒绝访问 file:// 协议，未通过其他浏览器或本地服务器绕过这一限制；可由使用者直接在自己的浏览器打开文件查看。

目前 63 个 Swift 文件通过语法解析，四个 Target 的源码引用完整，8 份属性清单、授权及隐私文件通过解析。源码差异检查通过，现有视图中的函数实现未改变；iOS 工作流仍仅手动触发，默认不生成包。本轮未运行 Xcode，也未生成新截图或安装包。Xcode 编译、图表实际渲染、底部导航、大小字体与完整点击流程将在用户确认后统一复验。

最近一次原生编译来自参考图改版前的 e920606：iPhone、Watch 编译通过，52 项客户端回归通过。UI 点击测试未全部通过：右对齐的体重框被脚本从开头插入数字，将 70 变成 7170，触发正确的体重范围校验。已将脚本改为从数值末尾清除、保存前断言 71，并等待录入页面关闭。该修正尚未复跑，不将旧截图或旧测试包作为本轮新 UI 的验收证据。

## 后续统一打包

iOS 工作流已移除 push 与 pull_request 自动触发，仅保留 workflow_dispatch。默认 create_packages 为 false，只执行编译、测试与截图。用户确认改动完成并要求打包后，再手动勾选 create_packages，生成手机 IPA 和模拟器 ZIP。后台自动测试和群晖镜像流程保持原触发规则。

本轮开始之前已生成的 0.1.7 手机包不包含参考图样式。不要将该旧包误认为本轮新界面的测试包。
